# Frontend Product UI Plugin

This plugin packages the canonical product-oriented workflow for frontend screens, dashboards, forms, games, browser experiences, and UI maps.

## Skills

- `frontend-product-ui`

## Ownership

Edit this skill only in the sibling AGENTS repository.
This directory is a generated deployable projection, and `source-lock.json` records its committed source revision.

## Synchronize

Run from the repository root:

```powershell
.\scripts\Sync-Plugins.ps1 -Plugin frontend-product-ui
.\scripts\Sync-Plugins.ps1 -Plugin frontend-product-ui -Check
```

## Install

```powershell
codex plugin add frontend-product-ui@callicrate
```

Start a new Codex thread after installation or refresh.
