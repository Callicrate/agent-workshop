# Propagation Rules for Skill Updates

Use these rules when one idea, pattern, or guardrail may need to be applied across more than one skill.

## Rule 1: Independent Skills Must Stand Alone

If a skill can be invoked by itself for the affected action, include the concept directly in that skill.

## Rule 2: Avoid Needless Duplication Across Co-Used Skills

If multiple skills are usually used together, keep the fullest wording in the most operationally central skill and use shorter aligned wording elsewhere.

## Rule 3: Do Not Rely on Hidden Cross-Skill Context

Never omit guidance that a skill needs for correct standalone behavior just because a related skill often appears in the same workflow.

## Rule 4: Prefer Concise Reusable Phrasing

When the same concept must appear in multiple skills, use short, consistent wording and push larger detail into references, scripts, templates, or assets.

## Rule 5: Preserve Discovery

If the concept changes when a skill should be invoked, update the skill description so automatic discovery still works.
